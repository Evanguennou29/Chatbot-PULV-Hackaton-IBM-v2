Vous disposez d'un quota de 18 absences autorisées par semestre. Au-delà, vous recevez un mail d'avertissement et un commentaire est inscrit sur votre bulletin. Le projet

En développement

Rendre le Help Center accessible par la conversation.

LeoChat est un prototype étudiant du hackathon IBM × Pôle Léonard de Vinci. Les réponses du Help Center servent de contexte à un modèle sur watsonx.ai, pour explorer une consultation en langage naturel.

Ce qui tourne aujourd’hui

Interface
Python / Flask
Génération
IBM watsonx.ai · modèle configurable
Connaissances
CSV local · 504 entrées initiales
Lancement
Docker Compose · données persistantes

Comment une réponse est produite

Le serveur assemble les paires « Entrée / Sortie » du CSV et la question étudiante dans un prompt. Le modèle génère ensuite la réponse. Les retours marqués comme utiles sont ajoutés au fichier local.

Ce qui reste à construire

La sélection des sources pertinentes, la vérification des réponses et la modération des retours. Le prototype envoie encore tout le CSV au modèle ; il ne dispose pas de recherche vectorielle. Une réponse jugée utile par un étudiant n’est pas une validation par la scolarité.
